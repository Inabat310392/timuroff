# BAYBOL — Google Form для анкеты клиента

Этот скрипт создаёт:

1. Google Form `BAYBOL — Анкета клиента`.
2. Все вопросы формы на русском языке.
3. Поле выбора страны: Польша / Словакия.
4. Полный набор анкетных данных, соответствующий стандарту BayBol из 27 полей.
5. Отдельную Google Таблицу `BAYBOL — НОВЫЕ АНКЕТЫ` для входящих ответов.
6. Служебный лист `СТАНДАРТ BAYBOL`, где каждому русскому вопросу сопоставлено английское поле рабочего стандарта.

## Как запустить

1. Открыть https://script.google.com/ под нужным Google аккаунтом BayBol.
2. Создать новый проект Apps Script.
3. Скопировать содержимое `Code.gs` в проект.
4. Запустить функцию `createBaybolClientForm`.
5. При первом запуске Google попросит разрешения на создание Формы и Таблицы. Разрешить доступ под рабочим аккаунтом BayBol.
6. После выполнения открыть журнал выполнения. Там будут три ссылки:
   - ссылка для клиентов;
   - ссылка для редактирования формы;
   - ссылка на таблицу ответов.

## Важно

На первом этапе форма НЕ пишет ничего в основную таблицу `Клиенты Baybol общ таблица`. Ответы идут только в отдельную входящую таблицу. Это сделано специально, чтобы клиентские ошибки не попадали напрямую в рабочую базу.

Следующий этап можно делать только после теста формы на нескольких анкетах: проверка ответа, сопоставление клиента по подтверждённым идентификаторам и безопасный перенос в основную таблицу.
